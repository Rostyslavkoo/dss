================================================================================
ALGORITHMS OVERVIEW
================================================================================

AVERBUKH (BFS):
  • Breadth-first spanning tree construction
  • Parallel neighbor exploration
  • 4-phase execution: waiting → exploring → collecting → finished
  • Message complexity: O(n + m)
  • Tree height: O(diameter)
  • Based on Baruch Awerbuch's 1987 foundational work

SIDON (DFS):
  • Depth-first spanning tree construction
  • Single-path sequential traversal
  • 4-phase execution: waiting → exploring → backtracking → finished
  • Back-edge detection with explicit BACK_EDGE messages
  • DFS level tracking for tree hierarchy
  • Message complexity: O(n² + m) worst case

LOGICAL CLOCKS:
  • Lamport: Counter-based happens-before ordering
  • Vector: Causal relationship and concurrency detection
  • Fully integrated into both algorithm implementations
