# Резюме: Реалізація Логічних Годинників

## Завдання

Реалізувати логічний годинник Лемпорта та векторний годинник на основі алгоритму Террі для встановлення причинно-наслідкового упорядкування подій у розподілених системах.

## Виконано

### 1. Логічний Годинник Лемпорта ✓

**Файл**: `scheduler/clocks/lamport_clock.py`

Реалізований простий лічильник, який забезпечує повне упорядкування подій:
- Інкремент на внутрішні события
- Синхронізація мітки часу при отриманні повідомлення
- Мінімальні накладні витрати (O(1) на процес)

```python
clock = LamportClock()
clock.increment_internal()
timestamp = clock.send_timestamp()
clock.receive_timestamp(received_timestamp)
```

**Властивості**:
- Простота реалізації та розуміння
- Забезпечує всім подіям цілком упорядкування
- Не розрізняє причинно-наслідкові та одночасні события

### 2. Векторний Годинник (Террі) ✓

**Файл**: `scheduler/clocks/vector_clock.py`

Реалізований вектор лічильників для виявлення причинно-наслідкових зв'язків:
- Один счётчик на кожен процес
- Методи для визначення причинно-наслідкових зв'язків (`happened_before`, `concurrent_with`)
- Повна інформація про знання кожного процесу

```python
vc = VectorClock(process_id=0, num_processes=4)
vc.increment_internal()
timestamp = vc.send_timestamp()
vc.receive_timestamp(received_vector)

# Аналіз
if vc1.happened_before(vc2_timestamp):
    # vc1 -> vc2 (причинно-наслідковий зв'язок)
elif vc1.concurrent_with(vc2_timestamp):
    # vc1 || vc2 (одночасні события)
```

**Властивості**:
- Точне визначення причинно-наслідкових залежностей
- Виявлення одночасних операцій
- O(n) накладні витрати, де n = кількість процесів

msg = TimestampedAction(

### 4. Вузол з підтримкою годинників ✓

**Файл**: `scheduler/implementation/node_with_clocks.py`

Реалізований вузел, що автоматично управляє логічними годинниками:
- Підтримує один або обидва типи годинників
- Автоматично інкрементує годинники на события
- Відправляє та обробляє timestamped повідомлення
- Ведення історії подій

```python
node = NodeWithClocks(
    node_id=uuid,
    neighbors=[...],
    process_index=0,
    num_processes=4,
    enable_lamport=True,
    enable_vector=True
)

# Відправка
msg = node.send_message_to(neighbor_id, data)

# Обробка
response = node.process_action(received_msg)

# Інформація
info = node.get_clock_info()  # {'lamport': 5, 'vector': [1,3,2,0]}
events = node.get_events()
```

### 5. Мережа з годинниками ✓

**Файл**: `scheduler/implementation/network_with_clocks.py`

Реалізована мережа, що управляє вузлами з логічними годинниками:
- Лінійна топологія (0-1-2-3) для демонстрації
- Методи для друку стану та історії
- Гнучка конфігурація (кількість вузлів, типи годинників)

```python
network = NetworkWithClocks(
    num_nodes=4,
    enable_lamport=True,
    enable_vector=True
)

network.print_clocks()   # Вивести поточні значення
network.print_events()   # Вивести історію подій
```
